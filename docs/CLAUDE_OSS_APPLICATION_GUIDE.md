# Panduan Lengkap Mendaftar Program "Claude for Open Source" (Anthropic OSS)

Dokumen ini memandu langkah demi langkah pendaftaran program **Claude for Open Source** dari Anthropic dengan repositori **OpenClaymation**.

---

## 1. Apa Itu Program "Claude for Open Source"?

Anthropic menyediakan program khusus bagi pengembang dan maintainer open source aktif di seluruh dunia. Penerima program mendapatkan:
- **Akses gratis Claude Max / Claude Ultra tier tertinggi** selama **6 bulan berturut-turut**.
- Akses prioritas API dan model mutakhir Claude (Claude 3.5 Sonnet / Claude 3.7 Sonnet).

Terdapat 2 jalur (Track):
1. **Maintainer Track**: Untuk repositori yang sudah memiliki 500+ dependent repos atau 200k+ downloads.
2. **Ecosystem Impact Track (Discretionary)**: **Jalur yang paling tepat untuk OpenClaymation**. Anthropic mencari developer/kreator yang membangun infrastruktur baru, integrasi tooling, dan implementasi Model Context Protocol (MCP) yang memperluas kemampuan Claude ke dunia nyata (seperti 3D animation, creative studio, dan Blender automation).

## 3. Template Jawaban Aplikasi (Siap Pakai dalam Bahasa Inggris)

Karena tim kurasi Anthropic berbasis di San Francisco (US), gunakan jawaban berbahasa Inggris profesional berikut saat mengisi formulir:

### Project Name
> `OpenClaymation`

### Project URL (Repository Link)
> `https://github.com/<username-github-kamu>/OpenClaymation`

### Primary Role in Project
> `Creator & Primary Maintainer`

### Brief Project Description (1-2 sentences)
> `OpenClaymation is an open-source autonomous 3D stop-motion and claymation production studio powered by Claude, the Model Context Protocol (MCP), and Blender. It enables Claude to autonomously stage physical tabletop miniature sets, apply procedural plasticine shaders with tactile fingerprints, and animate authentic 12 FPS stepped cadence.`

### How does this project impact the Claude / AI ecosystem? (Paling Penting!)
> `While most generative AI video tools produce flat, non-tactile 2D outputs with temporal inconsistencies, OpenClaymation bridges Claude directly into Blender's physics and rendering engine via MCP. It demonstrates the tangible power of Anthropic's Model Context Protocol for complex creative industries: Claude acts as an autonomous Director, orchestrating procedural shaders, 12 FPS stepped keyframing (animating on twos), miniature macro lighting, and audio-synced video assembly.`
> 
> `By open-sourcing this tool, we provide animators, indie filmmakers, and AI researchers with a 100% free, local, and reproducible alternative to proprietary closed models. Support from the Claude for Open Source program will allow us to expand the MCP toolset, integrate procedural clay face replacement rigs, and benchmark Claude Code's spatial reasoning in 3D production pipelines.`

## 4. Trik Mendapatkan Ratusan Stars & Forks Secara Cepat (Viral Strategy)

Agar repositori cepat mendulang ribuan stars dan forks:

### 1. Buat Demo Video/GIF Singkat (5-10 detik)
- Rekam satu clay ball atau karakter mitologi sederhana di Blender dengan tekstur clay bertekstur sidik jari yang melompat dengan ritme 12 fps stop-motion.
- Simpan sebagai GIF atau MP4 singkat dan taruh di header `README.md`. Konten visual clay selalu memancing reaksi emosional positif dari komunitas.

### 2. Posting ke Subreddit Target
- **r/ClaudeAI**: Beri judul: *"I built an open-source MCP server that lets Claude direct full 3D claymation stop-motion films in Blender (Wallace & Gromit style) [Open Source]"*
- **r/blender**: Beri judul: *"Procedural plasticine shader with fingerprints + 12fps stop-motion stepper for Blender (Free & Open Source)"*
- **r/LocalLLaMA** & **r/artificial**: Fokus pada arsitektur MCP dan otonomous pipeline-nya.

### 3. Posting di X (Twitter)
- Tag akun komunitas: `@AnthropicAI`, `@Blender`, `#MCP`, `#ClaudeCode`.
- Bagikan video perbandingan: *Smooth 3D CGI vs Authentic 12 FPS Stop-Motion Claymation generated by Claude*.

### 4. Kirim ke Show HN (Hacker News)
- Format judul: `Show HN: OpenClaymation – Autonomous 3D Stop-Motion Studio via Claude & MCP`
- Ceritakan motivasi: Menyukai stop-motion klasik (Aardman, Coraline) dan ingin membuktikan bahwa Claude + MCP bisa menggerakkan software industri seperti Blender.
